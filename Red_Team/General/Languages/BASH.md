### Variales
```
var="value"	  // Assign variable (no spaces!)
$var	      //  Use variable
${var}	      //  Use variable (explicit)
readonly var	// Make read-only
unset var	   // Delete variable
export var	  // Export to environment
env	         // List environment vars
```
